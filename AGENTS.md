# 榫卯课 Sunmao Joints: project guidance

Lesson app for PICO OS 6 Shared Space (Spatial SDK BOM 6.1.9), package `io.embodit.sunmaojoints`, v0.1.0. Design
contract: spatial-app-factory `apps/sunmao-joints/design-package.json` (v1.3, gate B passed 2026-11-18 with six
decisions: keep both this and the burr-lock app; 2.5x + a 1:1 mini; these 8 joints; tap the arrows only, hit areas >= 3° on the
near side; sound switch first in settings; [不拼了] without a confirm). Skeleton from the factory's burr-lock app (two
containers, theme, sound pool, level gate, board-input template); joints, sweep, flow, stage and scene are new.

## Surfaces
- **Volume** (default container `SunmaoJoints`, Volumetric 0.68 x 0.70 x 0.70 m, fixed scale, gravity, uniform resize).
  Origin at the volume centre, +x right, +y up, +z toward the user. Walnut turntable (Ø 0.40, top y −0.25, tap = 90°,
  stops at 45° / 135° / 225° / 315°), the joint on it (or on a 12 x 4 x 8 cm block), two mats at the front corners for
  the loose pieces, a walnut plaque at y +0.29 (one line, no collider), the 1:1 mini left of the turntable, teal arrows
  with 11 cm hit spheres (board-input holders), 35 % ghosts, an orange contact flash, the badge (S13 only).
- **Control window** (`SunmaoControl`, Planar 560 x 360 dp, `Placement.right(volume)`): native TabBar 榫卯 / 设置.
  设置: 音效, 错两次后提示, 语言, the disclaimer line, [怎么操作] (in-place view) and [退出应用] fixed at the bottom;
  [退出应用] turns the page into the question in place (S12) and closes both containers.

## Code
| Path | What |
|---|---|
| `domain/Geo.kt` | V3, Q, Pose, Aabb, `Prim` (polygon prism along x / y / z), `Piece`; RED prims are paint and never collide |
| `domain/Joints.kt` | the 8 joints in cm (2.5x), holes carved; steps, candidates (from 上 / 右前 / 左前), outcomes, signs (zh / en) |
| `domain/Sweep.kt` | `Motion` (candidate pose at push distance s) and the voxel sweep (U1–U3, U8) |
| `domain/JointTable.kt` | GENERATED by `ProbeTest` (`PROBE=1`): every candidate's stop (cm), contact box, trap bounce |
| `domain/Layout.kt` | metres: turntable, mats, plaque, mini, arrows (laid out per lesson x step x turntable stop for all three eyes: ≥ 3.2°, gaps ≥ 2.3°, ≥ 70 % visible; cached, warmed while loading), eyes |
| `domain/Flow.kt` | the single `PlayState` (S00–S10), timings `T`, taps / turns / pages, `Progress` + `SaveCodec` |
| `domain/Stage.kt` | pure frame: where every piece, ghost, arrow, flash is at time t; plaque line; x-ray opacity |
| `ui/board/*` | `MeshGen` (prims -> meshes), `SceneResources`, `BoardScene` (applies `Stage.frame` every ECS tick), `BoardScreen` (board-input) |
| `ui/control/*` | the window pages; every Text logs `OVERFLOW <tag>` when cut; buttons cannot take focus, pad keys eaten at the window root (D60) |
| `platform/BackKeys.kt` | BACK / controller B caught at every window (D60, gate back-key): window closed = reopen, else eaten; never exits |
| `tools/` | `make_sounds.py`, `loudness.py`, `build_icon.py`, `contrast.py`, `ll.sh` |

Regenerate the table after changing any geometry: `PROBE=1 ./gradlew :app:testDebugUnitTest --tests "*ProbeTest*"`.

## Debug broadcast (debug builds) and the QA shot list
```
adb -s <serial> shell am broadcast -a io.embodit.sunmaojoints.DEBUG -p io.embodit.sunmaojoints --es cmd <cmd> --es a "<arg>"
```
| State | Command (preconditions are built in) |
|---|---|
| S00 | cold start; the first ~1 s |
| S01 | `goto "1 S01"` (clears firstRunDone, lesson 1 → open → build) |
| S02 / S03 | `goto "<n> S02"` / `goto "<n> S03"` |
| S04 | `goto "<n> S04 <step>"` (taps the right arrows of the earlier steps) |
| S05 / S06 / S07 / S08 | `shot "S05|S06|S07|S08 <n> <step> <cand>"` freezes the frame (S06 = contact flash, S07 = bounce, S08 = x-ray of the last step); `hold off` to release |
| S09 | `goto "<n> S09"` |
| S10 | `goto "<n> S10"` (marks the other seven learned, then finishes lesson n) |
| S11 / S12 | `goto "1 S11"` / `goto "1 S12"`; how-to: `page howto` |
| S13 | `closecontrol` (badge appears; `replay badge` or a real tap reopens) |
| S14 | `corruptsave`, then force-stop and start |
| M1 / M2 / M3 | two misses (or `goto "1 S01"`) / `sound off` / `lang en` |
Also: `tap <i>`, `turn`, `hints on|off`, `doneall`, `reset`, `replay "<holder> [src]"`, `hover <holder>`, `evidence`, `dump`.
Every tap goes through `routeFlow` (same path as a real hit). `reset` clears progress (keeps the language).
